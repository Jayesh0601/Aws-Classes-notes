                        Cloud Deployment Types

 1. Public 

  - Infrastructure is owned by a cloud Provider.
  - Resources are shared among many customers
  - Accessible through the internet.
  - Cost is low because of shared infrastructure.
  - Best for startups, websites, and testing.
  - e.g. - AWS, Azure, GCP

 2. Private Cloud
         
  - Infrastructure is dedicated to single organization.
  - Can be hosted in the company's own data center or by a cloud provider.
  - Offers better security and control.
  - e.g. - Oracle, IBM 

 3. Hybrid Cloud

  - Combination of public cloud and private cloud.
  - Data and application can move between both environments.
  - Sensitive data stays in private cloud, while public workloads runs in public cloud.
  
 4. Multi-cloud(Latest Model)

 - Uses cloud services from multiple cloud providers.
 - Companies choose the best service from each provider.
